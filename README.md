# Частотний аналіз літер

Навчальний проєкт, варіант 7, лабораторна робота 1 з професійної практики програмної інженерії. Поточна технічна версія: **0.1.9**.

Програма підраховує кожну літеру в тексті без урахування регістру й виводить символьну стовпчикову діаграму. Коректний результат містить точні кількості кожної літери, загальну кількість та кількість різних літер.

## Середовище й запуск

Потрібен Python 3.10 або новіший. Сторонніх бібліотек і окремого збирання немає. У Windows за потреби замініть `python` на `py -3`.

```text
python main.py
Введіть текст: Абба! 123
Літера | Діаграма | Кількість
а ################################################## 2
б ################################################## 2
Усього літер: 4; різних: 2
```

Файл: `python main.py --file text.txt`. Файл повинен мати кодування UTF-8 (BOM допускається); обробляється весь багаторядковий текст. Довідка: `python main.py --help`.

## Правила підрахунку

- Нормалізація Unicode NFC об'єднує складені символи, наприклад `і` + діакритичний знак у `ї`.
- Враховуються Unicode-літери, зокрема українські ґ, є, і, ї. Пробіли, цифри й пунктуація не рахуються.
- Літери впорядковані за Unicode-кодом; латинська `a` та кирилична `а` різні.
- Стовпчики масштабуються пропорційно: найбільша частота має рівно 50 `#`. Округлення до найближчого цілого, половини вгору; мінімум один знак для додатної частоти. Числова кількість завжди точна.
- Помилкові дані: порожній текст, текст без літер, недоступний файл, файл не в UTF-8. Повідомлення друкується без traceback, код завершення 2. Успішне завершення має код 0.

## Перевірка

```text
python -m py_compile main.py
python -m unittest -v
```

Тести охоплюють регістр, українську абетку, нормалізацію Unicode, змішані абетки, діаграми, порожній ввід, файли UTF-8, хибне кодування й відсутній файл.
